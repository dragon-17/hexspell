A contenteditable has alreayd Undo/Redo prebuild. Only New line insert is akward. In Chrome --no guarantee for any other Browser/Device-- you can insert <br> instead of <div> with Shift+Enter and one global JS handler can do this behaviour automatically without Shift. The best is, that most Programms with RichText suport use the exakt same! so no need to relearn them. I even written keyboard shortcuts for VS-Code that use regex to toggle the selection for thes three and a list of more HTML elemtent. I must never write/remove <u><b><i> tags out manually.
