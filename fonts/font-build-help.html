Font Build helper

Brush
Use discrete grid to reduce options and acidental differences. Recommended size is 16*16 or 24*24 cells. This allows you to get inner rings
Transform
Create a new Webfont from a existing one (less work than designing all glyps)

Note: You can use a online converter e.g. from .ttf to .svg or install fontforge locally
