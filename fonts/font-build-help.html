SVG-Font Build/Detect helper

Info
Use discrete grid to reduce options and acidental differences. Recommended size is 16*16 or 24*24 cells. This allows you to get inner rings
Brush
Note: You can do both enter SVG code and brush via mouse move. When at mousemove-start the mouse pointer is not over the cursur character cell, then brushing is started. To still seelct text use a double click first or ensure your mouse pointer is already over the caret. For me this control works fine. Use Alt to use Eraser. Use Ctr make the Ramen-Peuker Filter less agressiv.
Import and Transform
Create a new Webfont from a existing one (less work than designing all glyps). This can load And extract from a .ttf font the svg-font glyphs.

Note: You can use a online converter e.g. from .ttf to .svg or install fontforge locally
